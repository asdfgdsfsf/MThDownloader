# MThDownloader
MThDownloader 是一款原生 Win32 多线程下载器，轻量绿色、无需安装，专为极致下载速度打造。  它支持 HTTP/HTTPS 直链与 BT 种子、磁力链下载：多线程自动探测带宽增益、动态增减线程，把网速榨干；下载接近尾声时自动细化分块、均衡调度，告别最后 1% 龟速。文件名自动识别填写，你只需选好保存目录；种子文件直接拖进窗口即可开始。  配合浏览器扩展，网页点击下载自动转入 MThDownloader 全速下载，专属面板实时显示进度、大小与耗时。所有配置保存在软件目录，拷走即用，双击启动。  快一点，再快一点——这就是 MThDownloader。
